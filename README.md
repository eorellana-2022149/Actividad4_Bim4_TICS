# Actividad4_Bim4_TICS
Acticidad 4 del cuarto bimestre de TICS

## Funcionalidades
- Consumo de la API pública JSONPlaceholder (`/users`) usando `fetch()`.
- Renderizado dinámico de tarjetas de usuario en el DOM.
- Filtro de búsqueda en tiempo real por nombre de usuario.
- Control de calidad de código automatizado con Husky y ESLint.
